# antipsikotik-atlas
Antipsikotik Reseptor Profili

Tipik ve atipik antipsikotiklerin reseptör bağlanma profillerini three.js ile 3B gösteren etkileşimli sayfa.

Site: https://lipsumation.github.io/antipsikotik-atlas/

- `index.html`: sayfanın tamamı (veri, stil ve kod tek dosyada)
- `vendor/three.min.js`: three.js r147 (MIT lisansı); yüklenemezse sayfa CDN'lere geçer

Eğitim amaçlıdır; tedavi kararı için kullanılmamalıdır.
